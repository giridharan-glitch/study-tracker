# 📚 Study Tracker

A simple Python-based Study Tracker that helps students record and manage their study sessions efficiently. This project allows users to track subjects, study hours, and monitor their learning progress.

## 🚀 Features

* Add study sessions
* Record subject names
* Track study hours
* View all study records
* Calculate total study hours
* Simple menu-driven interface
* Beginner-friendly Python project

## 🛠️ Technologies Used

* Python

## ▶️ How to Run

1. Clone the repository

```bash
git clone <repository-url>
```

2. Navigate to the project folder

```bash
cd study-tracker
```

3. Run the program

```bash
python student-tracker.py
```
